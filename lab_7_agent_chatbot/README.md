# Lab 7: Agent-Powered Chatbot Application

## Overview
Full-stack chatbot application combining agent capabilities with a modern web interface, featuring both backend API and frontend UI.

## Learning Objectives
- Build production-ready chatbot applications
- Integrate agents with web interfaces
- Implement real-time chat functionality
- Deploy full-stack AI applications

## Architecture
- **Backend**: FastAPI with agent integration
- **Frontend**: Modern web interface with real-time chat

## Setup

### Backend
```bash
cd backend
uv sync
uv run python main.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## Files
- `backend/` - FastAPI server with agent logic
- `frontend/` - Web chat interface
- `backend/main.py` - Main server application

## Usage
1. Start the backend server
2. Launch the frontend application
3. Interact with the agent-powered chatbot

## Features
- Real-time chat interface
- Agent-powered responses
- Tool integration
- Modern UI/UX
