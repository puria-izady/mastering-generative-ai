# 🚀 Mastering Generative AI

> **Transform your understanding of AI through hands-on labs that take you from neural networks to intelligent agents**

Welcome to the ultimate journey through the world of Generative AI! This comprehensive course combines cutting-edge theory with practical implementation, guiding you through 8 progressive labs that build real-world AI applications.

## 🎯 What You'll Master

From building your first neural network to deploying multi-agent swarms, you'll gain expertise in:

- **Deep Learning Foundations** - Neural networks and image classification
- **Creative AI** - Generate stunning images with Stable Diffusion and Nova Canvas  
- **Semantic Understanding** - Text embeddings and similarity search
- **Language Models** - Harness the power of LLMs for text generation
- **Conversational AI** - Build intelligent chatbots with memory
- **Autonomous Agents** - Create AI that can reason, act, and use tools
- **Full-Stack AI Apps** - Deploy production-ready AI applications
- **Multi-Agent Systems** - Orchestrate collaborative AI swarms

## ⚡ Quick Start

```bash
# Clone the repository
git clone <repository-url>
cd mastering-generative-ai

# Complete Lab 0 first to install UV
# Then set up environment
uv init --name mastering_genai
uv add jupyter boto3 torch torchvision transformers

# Install Jupyter kernel
uv run python -m ipykernel install --user --name mastering_genai --display-name "mastering_genai"

# Launch Jupyter
jupyter lab
```
