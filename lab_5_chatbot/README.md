# Lab 5: Building Intelligent Chatbots

## Overview
Create conversational AI systems using LLMs, implementing context management, memory, and interactive chat interfaces.

## Learning Objectives
- Build conversational AI systems
- Implement chat memory and context
- Design interactive chat interfaces
- Handle multi-turn conversations

## Setup
```bash
# From project root
uv add boto3 streamlit gradio
```

## Files
- `lab5.ipynb` - Core chatbot development
- `lab5_Bedrock.ipynb` - Bedrock-powered chatbot
- `Link.txt` - Reference materials

## Usage
1. Select the `mastering_genai` kernel in Jupyter
2. Run notebooks to build chatbot systems
3. Test interactive conversation flows

## Features
- Context-aware responses
- Memory management
- Multi-turn conversations
- Interactive interfaces
