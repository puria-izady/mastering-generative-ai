# Lab 6: Building LLM-based Agents with ReAct Framework

## Overview
Build intelligent agents using the ReAct (Reasoning + Acting) framework that can use tools, search for information, and interact with their environment.

## Learning Objectives
- Understand the ReAct framework and agent architecture
- Implement reasoning, action, and observation components
- Create tools that agents can use
- Test agents with various scenarios

## Setup
```bash
# Dependencies already configured in pyproject.toml
uv sync
```

## Files
- `lab6.ipynb` - Main agent development notebook
- `pyproject.toml` - UV project configuration
- `src/lab6/` - Agent implementation modules

## Usage
1. Select the `mastering_genai` kernel in Jupyter
2. Run `lab6.ipynb` to build ReAct agents
3. Experiment with different tools and scenarios

## Key Concepts
- ReAct framework (Reasoning + Acting)
- Tool integration
- Agent decision-making
- Environment interaction
