# Lab 4: Large Language Models (LLMs)

## Overview
Work with large language models using Amazon Bedrock, exploring text generation, completion, and various LLM capabilities.

## Learning Objectives
- Understand LLM architectures and capabilities
- Use Amazon Bedrock for text generation
- Implement prompt engineering techniques
- Explore different model parameters and settings

## Setup
```bash
# From project root
uv add boto3 transformers

# Configure AWS credentials
export AWS_ACCESS_KEY_ID=your_key
export AWS_SECRET_ACCESS_KEY=your_secret
export AWS_REGION=us-east-1
```

## Files
- `lab4.ipynb` - Core LLM experiments
- `lab4_Bedrock.ipynb` - Amazon Bedrock integration
- `Links.txt` - Reference materials

## Usage
1. Select the `mastering_genai` kernel in Jupyter
2. Configure AWS credentials
3. Run notebooks to experiment with LLMs
