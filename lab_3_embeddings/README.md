# Lab 3: Text Embeddings and Semantic Search

## Overview
Learn to create and use text embeddings for semantic search, similarity matching, and document retrieval.

## Learning Objectives
- Understand text embeddings and vector representations
- Implement semantic search algorithms
- Build document similarity systems
- Work with embedding models

## Setup
```bash

uv add sentence-transformers numpy scipy faiss-cpu
```

1. Select the `mastering_genai` kernel in Jupyter
2. Run `lab3.ipynb` to explore embeddings
3. Experiment with different text similarity tasks
